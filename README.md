# 语径 Lingua · 多语种沉浸式学习平台

## 项目简介

「语径 Lingua」意为「通往语言的路径」。平台以分级课程为骨架、沉浸互动为肌理，
让单词、语法、听力和口语在真实语境中生长。每位学习者都拥有独立的学习档案，
系统会追踪每一次进步，并基于目标与节奏推荐专属学习路径。

## 核心能力

| # | 能力 | 说明 |
|---|------|------|
| 1 | 分级课程体系 | 英语对标 CEFR（A1~C2）、日语对标 JLPT（N5~N1）、韩语对标 TOPIK（1~6급），含等级轴可视化与课时建议 |
| 2 | 互动式学习模块 | 单词记忆（翻面闪卡 + TTS 朗读）、语法练习（选择题 + 自动判分）、听力训练（语音合成 + 理解题）、口语跟读（示范朗读 + 真实录音） |
| 3 | 学习进度追踪 | 进度环（含部分进度）、四技能均衡条、本周打卡日历、近两周活跃热力图、连续学习天数 |
| 4 | 用户注册登录 | 基于 localStorage 的账号体系，每账号独立命名空间存档，支持注册 / 登录 / 退出 |
| 5 | 个性化学习路径推荐 | 两步引导（学习目标 + 每日节奏），按目标生成多语种推荐路径与模块顺序 |
| 6 | 社区交流 + 成就激励 | 话题发布 / 点赞 / 回复、本周活跃榜、9 枚成就徽章（连续 / 经验 / 课时 / 语种 / 满分）自动解锁 |

## 美学方向

**编辑式语言学院（Editorial Language Institute）** 风格：

- 暖纸底色 + SVG 噪点纹理，营造印刷质感
- Fraunces 衬线展示字配 Manrope 正文
- 三语种文化点缀色，随语种切换动态主题色
  - 英语 · 深青（英伦沉稳）
  - 日语 · 朱红（和风 Vermillion）
  - 韩语 · 紫梅（韩韵 Plum）
- 卡片堆叠与翻面动效、不对称网格、留白与密度并存

## 技术栈

- **HTML5** —— 语义化结构
- **CSS3** —— CSS 变量、Grid、Flexbox、动画、SVG 纹理
- **原生 JavaScript** —— 无框架、无构建工具
- **localStorage** —— 账号、进度、成就、社区话题持久化
- **Web Speech API** —— 语音合成（听力朗读与口语示范）
- **MediaRecorder API** —— 口语跟读真实录音

> 纯前端实现，无需服务端，打开即用。

## 快速开始

### 方式一：直接打开

双击 `index.html` 即可在浏览器中使用。

> 注意：部分浏览器对 `file://` 协议下的 localStorage 与语音合成有限制，推荐使用方式二。

### 方式二：本地服务器（推荐）

```bash
# 进入项目目录
cd 在线教育

# Python 3
python -m http.server 8000

# 或 Node.js（需先 npm i -g serve）
serve -p 8000
```

浏览器访问 http://127.0.0.1:8000/ 即可。

## 使用指南

1. **注册账号**：点击右上角「登录」→「立即注册」，填写昵称、账号、密码
2. **完成学习引导**：首次登录后选择学习目标（如出国旅行）与每日节奏（如标准模式）
3. **开始学习**：系统会生成推荐路径，点击「开始这条路径」进入课程
4. **完成模块**：依次完成单词记忆、语法练习、听力训练、口语跟读四个模块
5. **查看进度**：在「学习中心」查看进度环、技能均衡度、打卡日历与活跃热力图
6. **解锁成就**：完成课程、连续打卡、积累经验可自动解锁成就徽章
7. **社区交流**：在「社区」发布话题、点赞回复、查看本周活跃榜

## 互动学习模块说明

### 单词记忆
翻面闪卡设计：正面显示单词与音标，点击翻面查看释义与例句；支持 TTS 朗读单词与例句。

### 语法练习
基于课程语法点自动生成选择题，从例句池构造干扰项，选择后即时判分并高亮正确 / 错误选项。

### 听力训练
使用浏览器原生语音合成朗读场景对话，播放时显示声波动画；听完后完成理解题，可查看原文参考。

### 口语跟读
逐句展示短语、翻译与发音提示；点击喇叭播放示范朗读，点击麦克风可调用浏览器录音权限进行真实跟读录音（不支持录音时自动模拟）。

## 课程数据

| 语种 | 等级体系 | 单元数 | 内容覆盖 |
|------|---------|--------|----------|
| 英语 | CEFR A1~C2 | 4 | 问候、日常作息、旅行、观点表达 |
| 日语 | JLPT N5~N1 | 3 | 寒暄、每日生活、购物 |
| 韩语 | TOPIK 1~6급 | 3 | 问候、一天生活、购物 |

每个单元包含：
- 5 个核心词汇（含音标、释义、例句）
- 1~2 个语法点（含句型、解析、例句）
- 1 段听力素材（含原文、音频文本、2 道理解题）
- 2~3 句口语跟读短语（含翻译、发音提示）

## 纯前端的局限

| 方面 | 当前状态 | 局限说明 |
|------|---------|---------|
| 账号系统 | localStorage 明文存储 | 无加密、无服务端校验，清浏览器数据即丢失 |
| 数据同步 | 仅限当前浏览器 | 换设备 / 换浏览器无法同步进度 |
| 社区交流 | 本地模拟 | 其他用户看不到你发的话题 |
| 课程内容 | 静态写死在 data.js | 无法后台动态更新 |
| 语音识别 | 无 | 口语跟读只能录音，不能自动评分 |

## 浏览器兼容性

推荐使用最新版 **Chrome / Edge / Firefox**。
- 语音合成（TTS）需要浏览器支持 Web Speech API
- 口语录音需要浏览器支持 MediaRecorder API 与麦克风权限
- 移动端基本可用，但推荐桌面端体验完整功能
